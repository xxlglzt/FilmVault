# FilmVault · 个人影音管理系统

参考 [peach](https://github.com/peach-mitao/peach) 的 local-first 架构：
单进程 FastAPI + SQLite，数据全部落在本地 `data/` 目录，刮削源可插拔。
专注于**国内外电影/电视剧**管理，评分体系对标豆瓣（10 分制、想看/在看/看过、短评、标签）。

## 功能

- **全自动整理媒体库**：可视化选择本机目录，后台自动搜索、创建条目、缓存海报并整理电影和季集；重复扫描自动跳过已入库文件
- **容错文件名识别**：支持 `S01E02`、`1x02`、`第x季第x集`、常见发布标记和中英文标题；文件名不完整时尝试使用父目录名
- **文件识别维护**：在「文件管理」中重新自动识别、搜索源站纠正匹配，或在源站缺失时手工创建作品；保留播放进度
- **Netflix 风格界面**：深色精选横幅、横向海报列表、电影/电视剧筛选和移动端适配
- **豆瓣评分体系**：半星粒度（每星 2 分）的个人评分、五种标记状态、短评、标签和统计页
- **自动元数据**：默认使用豆瓣（非官方、可能受反爬限制）；可选 TMDB API Key 增强国外影视识别并补全季集
- **双播放方式**：网页播放器或 PotPlayer、VLC 等本地播放器；电影和电视剧均同步进度，90% 自动标记已看
- **本地播放监控**：VLC 实时同步实际位置，其他播放器关闭后按本次播放时长同步；在设置页配置播放器程序路径

## 运行

```bash
pip install -r requirements.txt
scrapling install  # 可选：没有 Chrome/Edge 时安装反爬回退浏览器
python run.py
```

浏览器打开 http://127.0.0.1:8800 ，点击「扫描媒体库」并选择目录即可。TMDB Key 是可选项，需要时可在「设置」页填写。

## 目录结构

```
app/
  main.py        FastAPI 路由（REST + 视频流 + 静态页面）
  db.py          SQLite schema 与连接
  library.py     本地视频文件名解析 / 目录扫描
  player.py      本地播放器启动 / VLC 实时监控 / 进度同步
  scrapers/      tmdb.py / douban.py / base.py（可插拔源）
  static/        单页前端（无构建依赖）
data/            运行期生成：filmvault.db + posters/
run.py           启动入口
```

## 备份

复制整个 `data/` 目录即可（数据库 + 海报都在里面）。
